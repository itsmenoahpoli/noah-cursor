Commands

CLI reference for managing the registry. Default IDE is Cursor ((--ide cursor). Pass --ide for Windsurf, Claude Code, and others.

On this page

  1. Overview
  2. browse
  3. add
  4. search · list · remove · update · doctor

Overview

Command Description
browse Pick IDE → browse categories → install assets
add Install Skills, Rules, Prompts, MCP, or Presets
search Search the registry
list List registry or installed assets
remove Uninstall an asset
update Re-fetch and update installed assets
doctor Diagnose environment health

browse

Select IDE → Select categories → Select assets → Confirm → Install

noah — zsh 
$ npx noah-cursor browse$ npx noah-cursor browse --ide windsurf$ npx noah-cursor browse --browse-skills$ npx noah-cursor browse --browse-rules
↑↓ navigate Space select A toggle all I invert Enter confirm Esc cancel

add

Always installs from Noah’s bundled registry.

Flag Purpose
--skill <name> Install a skill
--rule <name> Install a rule
--prompt <name> Install a prompt
--mcp <name> Install an MCP config
--preset <name> Install a preset
--ide <name> cursor (default) · windsurf · claude-code · continue · vscode · cline
--all Install everything from the registry
--force · --dry-run · --yes · --verbose Overwrite, preview, skip prompts, or log more
noah — zsh 
$ npx noah-cursor add --skill commit-push$ npx noah-cursor add --skill commit-push --ide claude-code$ npx noah-cursor add --rule nextjs-marketing$ npx noah-cursor add --all

search · list · remove · update · doctor

Pass --ide when managing installs for a non-Cursor target.

noah — zsh 
$ npx noah-cursor search doctor$ npx noah-cursor list$ npx noah-cursor list --installed --ide windsurf$ npx noah-cursor remove skill test --yes$ npx noah-cursor update --yes$ npx noah-cursor doctor --ide claude-code
