Cursor setups that actually ship.

Install battle-tested Skills, Rules, and workflows into .cursor/ — one command, no clone, no sign-in.

View on npm

Install in three moves

Built for Cursor first. Pick another IDE when you need it.

  1. 01

    Select IDE

    Defaults to Cursor. Or choose Windsurf, Claude Code, Continue, VS Code, or Cline.

  2. 02

    Browse the registry

    Skills, Rules, Prompts, MCP configs, and Presets — curated and versioned.

  3. 03

    Land in the right folder

    Assets install under .cursor/ by default — or that IDE’s project root.

Folder follows your IDE

Same registry. Destination depends on what you pick.

  • Cursor .cursor/ default
  • Windsurf .windsurf/
  • Claude Code .claude/
  • Continue .continue/
  • VS Code .vscode/
  • Cline .cline/

Skills worth installing

Workflows you reuse across every Cursor project.

  • commit-push Stage, group, commit, push — clean every time
  • generate-readme Project README with stack, deps, and setup
  • react-doctor-fix Run react-doctor, fix findings, verify
  • larastan-fix Larastan on Laravel — fix and verify
  • nestjs-knip-fix Knip unused code out of NestJS
  • node-doctor-fix Node hygiene with Knip + doctor

Try it in your terminal

Node.js 20+. Registry ships in the package.

$ npx noah-cursor browse
$ npx noah-cursor add --skill commit-push
$ npx noah-cursor add --skill commit-push --ide windsurf
