How it works

Noah Cursor is a CLI + bundled registry. You pick an IDE, choose assets, and they install into that IDE’s project folder — Cursor by default.

Install flow

Interactive install is the recommended path.

  1. 01

    Select IDE

    Defaults to Cursor. Or choose Windsurf, Claude Code, Continue, VS Code, or Cline.

  2. 02

    Browse categories

    Skills, Rules, Prompts, MCP configs, and Presets — curated and versioned in the package.

  3. 03

    Confirm & install

    Assets copy into the IDE root (e.g. .cursor/). No clone, no sign-in.

IDE folders

Same registry. Destination depends on what you pick (or pass with --ide).

  • Cursor .cursor/ default
  • Windsurf .windsurf/
  • Claude Code .claude/
  • Continue .continue/
  • VS Code .vscode/
  • Cline .cline/

What lands in the project

Inside the IDE root (example for Cursor):

.cursor/
  skills/commit-push/
  rules/laravel-api/
  prompts/
  mcp/
  noah.json   # tracks installs + ide

noah.json

After install, noah.json records versions, the target IDE, and registry metadata so update and remove stay reliable across machines and teammates.

Quick start

Requires Node.js 20+. Registry ships inside the package.

noah — zsh 
$ npx noah-cursor browse$ npx noah-cursor add --skill commit-push$ npx noah-cursor browse --ide windsurf
